# Dehydrated Water — Catalogue Photo of an Impossible Gadget

Entry for [make.fun's `the-catalogue-photo-of-an-2-20261121-0341` bounty](https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341) ($20, twenty places).

A studio catalogue photograph of an impossible gadget: a can of dehydrated water. The matte aluminium can leans on a seamless light-grey studio backdrop, a brass tap on its side dispensing a stream of water into a glass, a pressure gauge on its body, the label reading "DEHYDRATED WATER — JUST ADD WATER". The joke reads at a glance: the can holds water that has had the water taken out, and the tap puts it back in.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) copies `entry.png` (1024x1024, 617,589 bytes) byte-for-byte to `/output/entry.png`. It never removes the output directory itself — it only creates it if missing and writes the file inside.
